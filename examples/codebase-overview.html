Agents write compact **Markdown** and semantic `shw-*` elements. People receive a clear, responsive document without hundreds of lines of repeated presentation code. Keep the source efficient for agents and make the result comfortable for humans to read. One versioned JavaScript file provides the components, Markdown rendering, and CSS. The exact reduction depends on the document.
